ROM Images for Various IBM PC Family Devices


The intention of this webpage is simply to provide content, that without modification, is suitable to populate a replacement ROM/EPROM  (e.g. create a replacement ROM/EPROM of version 4.66 to replace a faulty version 4.66 ROM/EPROM).

Out of scope is upgrade information.  If you are seeking a version upgrade, then 'do the research'.  Some upgrades have special hardware requirements/considerations.  It is known that some upgrades require different switch settings.

The 'Make' and 'Model' columns show the parent device that the ROM image was created from.  The ROM image may also be suitable for other make-models.  It is not in this webpage's scope to identify all possible uses of a particular ROM image.

Sum:  Checksum (via simple byte addition)
Copy:  How the image was created. D=direct (e.g. from EPROM programmer) C=computer (using computer [e.g. DEBUG software])
Source:  Person at the VCFF (or at phantom.sannata.ru) who supplied the image.  Note that the supplier isn't necessarily the same person who created the image.

Note that an image created by a computer is not always suitable (i.e. without modification) for use in a replacement EPROM.  It depends on the device.  For example, the content of the ROM on an IBM EGA card is ordered differently to how the content is presented to the computer.  That is why the preference is always for an image to be created directly, via an EPROM programmer.
