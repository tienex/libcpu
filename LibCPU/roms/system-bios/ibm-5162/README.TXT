
This is the first and only BIOS for the IBM 5162.
It is dated 21APR86 (04/21/86).


+---------------------------------+
|  GENERAL                        |
+---------------------------------+

ROM chip U34 has the IBM part number of 78X7460, and is 32K in size
ROM chip U35 has the IBM part number of 78X7461, and is 32K in size


8 bit checksum of 78X7460 = C5
8 bit checksum of 78X7461 = 3B
                           ----
                    added = 00


+---------------------------------+
|  FILES                          |
+---------------------------------+

File BIOS_5162_21APR86_U34_78X7460_27256.BIN is a binary image of ROM chip U34.  [ 32 KB in size ]
File BIOS_5162_21APR86_U35_78X7461_27256.BIN is a binary image of ROM chip U35.  [ 32 KB in size ]


+---------------------------------+
|  USING FILES TO MAKE EPROMS     |
+---------------------------------+

1. Obtain two blank 27256, or 27C256, EPROM's rated at 250 ns (or less [faster]).

2. Burn file BIOS_5162_21APR86_U34_78X7460_27256.BIN to the first 27256, then label the 27256 as "U34".

3. Burn file BIOS_5162_21APR86_U35_78X7461_27256.BIN to the second 27256, then label the 27256 as "U35".
